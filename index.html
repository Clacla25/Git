HTML qu'est ce que c'est ?

Le HTML est un language de balisage, qui permet de donner le fond du site, ce dont il va traiter le texte mais aussi d'attribuer la hierarchie. La "nature" du texte mi dedans (ex: titre, lien, paragraphe, image,...) Voici un lien qui répertory les principales balises : SheetCheat HTML

CSS qu'est ce que c'est ?

Le CSS est lui aussi un language de balisage, lui permet de donner la forme du site, à quoi va ressembler le texte, les balises (ex: gras, centrage du texte, couleur,...). On peut choisir d'appliquer une mise en forme particulière à certaines balises particulières (tout les titres, tout les paragraphes,...), mais on peut également faire une mise en forme spécifique. Soit on identifira avec un ID (numéro unique) et on indiquera ce qu'on souhaite lui appliquer (si on ne veut que ça s'appliquer cas une paragraphe en particulier). Soit par une classe (noms qu'on peut attribuer a qui on souhaite) et qui permet d'attribuer une mise en forme à toute les balises de la classe peut importe le type de balise que c'est.
